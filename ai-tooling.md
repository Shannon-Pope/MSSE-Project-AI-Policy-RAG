# AI Tooling

## Overview

AI-assisted development tools played a major role in the design, implementation, troubleshooting, and documentation of this project. I used these tools as development assistants to help with learning/understanding concepts, solve technical issues, and to improve productivity throughout the software development lifecycle.

## AI Tools Used

### ChatGPT

ChatGPT was used as a project mentor and planning assistant throughout development.

Primary uses included:

* Breaking the project into manageable phases
* Creating project checklists and implementation plans
* Explaining RAG architecture concepts
* Providing guidance on Flask application structure
* Assisting with evaluation methodology and metrics
* Helping create project documentation

#### What Worked Well

* Excellent for clarifying concepts
* Helpful for creating step-by-step implementation plans
* Useful for generating documentation templates and examples
* Effective at explaining software engineering best practices

#### Challenges

* Generated code occasionally required modification to fit the specific project structure
* Some recommendations required additional validation before implementation

### Claude Code

Claude Code was the primary coding assistant used during implementation and troubleshooting.

Primary uses included:

* Generating application code
* Creating and refining the RAG pipeline
* Debugging Flask application issues
* Troubleshooting dependency and environment problems
* Resolving GitHub Actions workflow issues
* Troubleshooting deployment failures on Render
* Assisting with API integration and error handling

#### What Worked Well

* Particularly effective for debugging and troubleshooting
* Strong at identifying root causes of deployment and configuration issues
* Helpful for refactoring code and improving structure
* Provided good suggestions when errors occurred

#### Challenges

* Some generated solutions required iterative refinement
* Troubleshooting often required multiple cycles of testing and adjustment before a final solution was reached

### GitHub Copilot

GitHub Copilot was used primarily within Visual Studio Code as a coding productivity tool.

Primary uses included:

* Code completion
* Boilerplate generation
* Syntax suggestions
* Error identification within workflows and configuration files

#### What Worked Well

* Accelerated routine coding tasks
* Reduced time spent writing repetitive code
* Helpful for identifying syntax issues in YAML workflow files

#### Challenges

* Suggestions were not always contextually correct
* Generated code still required review and testing

### GitLens

GitLens was used to improve source control workflow and repository management.

Primary uses included:

* Creating descriptive commit messages
* Reviewing code changes
* Understanding file history and revisions

#### What Worked Well

* Simplified Git workflow management
* Improved commit message quality and consistency
* Made it easier to track project progress

#### Challenges

* Limited direct impact on application development compared to the coding assistants

## Lessons Learned

AI tools significantly accelerated development and improved productivity throughout the project. The most valuable use cases were project planning, debugging, deployment troubleshooting, and documentation generation.

However, successful project completion still required working knowledge of software engineering fundamentals, including testing, debugging, validation, and understanding how the various system components worked together. AI-generated code and recommendations were reviewed, tested, and modified as needed before being incorporated into the final solution.

The combination of ChatGPT for planning and learning, Claude Code for implementation and troubleshooting, GitHub Copilot for coding assistance, and GitLens for source control support created, overall, an effective AI-assisted development workflow that improved both productivity and learning outcomes.
